SELETORES

Seletores por Atributos

Este seletor básico irá escolher todos os nós. Ele também existe em um namespace único e em uma variante de todo o namespace também.

SINTAXE: elemento[atributo="valor"]



Seletores de Descendentes

Seleciona todos os elementos que estejam aninhados dentro de um elemento pai, independentemente do nível de profundidade (filhos, netos, bisnetos, etc.

SINTAXE: selector1 selector2 {/* property declarations */}



Seletores Filho Direto

Seleciona apenas os elementos que são filhos imediatos de um elemento pai, ignorando netos ou níveis mais profundos.

SINTAXE: pai > filho_direto



Seletores Adjacente Direto

Seleciona um elemento que é o próximo irmão imediato de outro, ou seja, que vem logo após ele e compartilha o mesmo pai.

SINTAXE: elemento1 + elemento2



Seletores de Irmãos Gerais

Seleciona todos os elementos irmãos que vêm depois de um determinado elemento de referência na estrutura do código, mesmo que existam outras tags entre eles.

SINTAXE: elemento1 ~ elemento2



Seletores de Pseudoclasse

estado especial ou em interações do usuário (como passar o mouse, foco no input ou ordem estrutural).

SINTAXE: elemento:pseudoclasse



Seletores de Pseudoelemento

Utilizado para estilizar partes específicas de um elemento ou para injetar conteúdo puramente visual via CSS sem modificar o arquivo HTML.

SINTAXE: elemento::pseudoelemento
